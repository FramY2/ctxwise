# v0.4.0 one-command context snapshot — TDD evidence

## User journey

As a Codex user, I want one local command to tell me what contributes most to
known startup context, what remains unmeasured, and what I can safely inspect
next without calling a model or changing configuration.

## RED

- Test commit: `9cd3cb2 test: define one-command context snapshot`

- Result: the unit suite could not import `audit-summary.js`, and the process
  test failed because `snapshot` was an unknown command.

## GREEN

- Implementation commit: `d86c446 feat: add one-command context snapshot`
- The targeted unit and process suites pass.
- Ranking uses only positive, explicitly estimated contributors.
- Configuration and MCP schema surfaces remain unmeasured; they are never
  converted to zero.
- Output contains paths and metadata already exposed by the audit, never file
  contents or configuration values.
